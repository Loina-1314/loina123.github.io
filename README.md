# Loina 三合一 · 单文件站点 README

> 一个完全自包含的单文件个人站：主页外壳 + MiNa 离线词典 + Mango 播放器，全部收在一个 `index.html` 里，双击即可离线运行。

---

## 1. 项目简介

**Loina 三合一**是艺名 Loina 的个人站点，由三层组成：

1. **主页外壳**：深蓝星空氛围的单页主页，含导航、音乐作品、玻璃声场录音室、MiNa AI 引擎板块、开发项目、留言板、联系方式；
2. **MiNa 词典**：以 `iframe` 沙箱隔离的离线词典，内置高中/大学词库与本地 TTS；
3. **Mango 播放器**：以 `iframe` 沙箱隔离的本地音乐播放器，支持 LRC 歌词、ID3 封面提取。

两个子应用的完整源码以 base64 内联在主页中，运行时解码注入 `iframe` 的 `srcdoc`，因此**没有任何外部文件依赖**。

## 3. 快速开始

### 本地运行

直接双击 `index.html`，或拖进浏览器即可。`file://` 协议下所有功能（含本地存储、iframe 沙箱、音频合成）均可用。

### 部署到静态托管

因为是纯静态单文件，可直接发布到任意静态托管：

- GitHub Pages / Vercel / Cloudflare Pages：把 `index.html` 作为入口上传即可；
- 豆包 HTML 应用：在文件所在目录执行 `lark-cli apps +deploy --file-path ./index.html`；
- 无需构建步骤，无环境变量，无后端。

### 浏览器要求

使用现代 Chromium 内核浏览器（Chrome / Edge / Arc 等）。依赖 `backdrop-filter`、`postMessage`、`FileReader`、Web Audio 等标准能力，不兼容 IE。

## 4. 技术架构

```
┌─────────────────────────────────────────────┐
│  index.html · 主页外壳（浅/深色主题、导航）   │
│                                             │
│  ┌───────────────┐   ┌───────────────────┐  │
│  │ iframe        │   │ iframe            │  │
│  │ #frame-dict   │   │ #frame-player     │  │
│  │ MiNa 词典      │   │ Mango 播放器       │  │
│  │ srcdoc 注入    │   │ srcdoc 注入        │  │
│  └───────────────┘   └───────────────────┘  │
│         ▲ postMessage 双向通信 ▲             │
└─────────────────────────────────────────────┘
```

- 主页定义 `var FRAME_B64 = {"dict":"<base64>","player":"<base64>"}`，经 `b64ToUtf8()` 解码后写入两个 iframe 的 `srcdoc`；
- 父子之间**只通过 `window.postMessage` 通信**，不共享 DOM、不共享样式，子应用样式不会污染主页；
- 所有脚本均为独立 IIFE，模块间不挂全局变量。

## 6. 设计系统

### 6.1 主题变量

`:root` 定义整套设计令牌，所有组件只引用变量、不写死颜色：

| 变量 | 用途 |
| --- | --- |
| `--primary` / `--primary-d` | 主色与按下态 |
| `--primary-soft` | 主色浅底（标签、选中态） |
| `--grad` | 主渐变（按钮、头像、图标底） |
| `--bg` / `--card` | 页面底 / 卡片底 |
| `--text` / `--text-light` | 正文 / 次要文字 |
| `--line` | 边框与分隔线 |
| `--glass` / `--glass-border` | 毛玻璃表面与描边 |
| `--shadow` / `--shadow-lg` | 阴影层级 |

默认（薰衣草紫）主色 `#7c8cf0`，主渐变 `linear-gradient(135deg,#7c8cf0,#a58be8 55%,#c99be8)`。

### 6.2 明暗模式

- `<html data-theme="dark">` 切换暗色，选择写入 `localStorage.theme`，下次打开自动恢复；
- 暗色下毛玻璃变量、Hero 背景、卡片底色均有对应覆盖规则。

### 6.3 三套渐变主题（Accent）

顶栏「外观」按钮打开外观面板，提供三套渐变主题，选择写入 `localStorage.loinaAccent`：

| data-accent | 名称 | 风格 |
| --- | --- | --- |
| `strawberry` | 草莓粉 | 粉系渐变 |
| `peach` | 蜜桃橙 | 暖橙渐变 |
| `lavender` | 薰衣草紫（默认） | 蓝紫渐变 |

每套主题在明暗两种模式下各有一组变量，共 6 种组合。

### 6.4 视觉语言

- **毛玻璃**：`backdrop-filter: blur()` + 半透明表面 + 细描边，用于胶囊、Dock、声场光控条；
- **渐变**：统一 135° 主渐变，用于按钮、头像、图标容器；
- **入场动画**：`.reveal` / `.lab-fade` 初始下移透明，`IntersectionObserver` 进入视口加 `.on` 淡入；
- **断点**：主页 `960px / 640px`，玻璃声场 `980px / 560px`；窄屏优先，手机端导航横向滚动、网格降为单列。

### 7.3 玻璃声场（`#studio`）

深冷虚空背景上的悬空弧形玻璃腔体，核心视觉元素：

| 元素 | 说明 |
| --- | --- |
| `.lab-veil` ×2 | 两层天光渐变背景 |
| `#labSnow` | canvas 雪粒，进入视口才启动 |
| `.lab-goose` ×3 | 寒雁虚影，64/88/102 秒缓慢横移，窄屏隐藏 |
| `.lab-shell` | 弧形玻璃腔体，边缘高光 + 弧形眩光 + 左右渐隐 |
| `.lab-ribbons` | 四条贝塞尔光带，常显缓慢流动，启动后收紧节奏 |
| `.lab-orb / .lab-ripple` | 中央呼吸光点 + 三圈扩散波纹 |
| `.lab-holo` | 空中光控胶囊：场景名、状态、四场景切换、启动按钮 |
| `.lab-facts` / `.lab-quote` | 四条事实卡片与收束引文 |

四个声场场景（旷野 / 长岸 / 寒山 / 空场）各有独立的雪粒密度与流速参数；启动声场后光带与光点同步收紧，再次点击静默收声。

### 7.4 AI 概念工程矩阵

声场下方的概念功能矩阵，共 **14 个深色玻璃卡片**，**点击只响应「待开发中」提示**，不执行任何真实处理：

| 批次 | 功能 |
| --- | --- |
| 首批 6 项 | AI 母带、AI / 原创音乐分轨、音质提升、音频转 MIDI、音轨合成、MIDI 转音谱 |
| 追加 8 项 | AI 扒谱 / 多乐器转谱、AI 降噪、人声修复 / 人声增强、音色克隆 / 声音克隆、AI 翻唱 / 声音转换、AI 自动混音、音乐视频 / MV 生成、音频格式转换 |

桌面 3 列、平板 2 列、手机单列，每个卡片带独立线形图标与「待开发」标签；点击事件由统一 IIFE 委托，`preventDefault + stopPropagation`。

### 7.5 MiNa AI 板块（`#ai`）

按 Loina 主页风格重做的概念级多模态引擎展示，不使用宣传片的原始配色，全部跟随设计令牌与 accent 主题：

| 模块 | 内容 |
| --- | --- |
| 三大引擎卡 | MiNa Q3 极速对话、MiNa Q4 均衡多面手、MiNa Q4.5 Pro 全能旗舰，各带 3 条能力点与「概念规划」标签 |
| 八项能力卡 | 文本与文档、代码与数据、多模态生图、Agent 工具链、语音与听觉、视频与动效、知识库与检索、翻译与本地化 |
| 案例区 | 左侧「全透明玻璃质感虚拟录音棚」Prompt → 右侧终端生成的 `MiNa.Studio` 配置，呼应玻璃声场 |

响应式：桌面引擎 3 列 + 能力 4 列；960px 以下 2 列；手机引擎单列、能力卡 2 列，案例区竖排且箭头转向下。

### 7.6 留言板（`#guestbook`）

评论区式本地留言，无点赞按钮：

- 顶部发布区：头像 + 200 字输入框 + 署名（12 字，留空为「匿名旅人」）+ 字数计数 + 发布；
- 每条留言可点「回复」，在本条下方展开输入行，回复以左侧竖线缩进平铺，前缀 `回复 @某某：`；
- 支持「最新 / 回复最多」排序；底部「清空本机留言」需确认；
- 数据存 `localStorage['loinaGuestbook']`，最多 60 条主留言；首次打开注入 1 条站长置顶；
- 内容按纯文本渲染，不解析 HTML，防注入；
- 快捷键：`Ctrl/⌘+Enter` 发布，回复框回车发送。

数据结构：

```json
[
  {
    "id": "m...",
    "n": "昵称",
    "c": "正文",
    "t": 1770000000000,
    "reps": [
      { "id": "m...", "n": "昵称", "c": "回复正文", "t": 1770000001000, "to": "被回复者" }
    ]
  }
]
```

`t:0` 表示站长置顶（显示「站长」标签与「置顶」时间）。

### 7.7 电台胶囊（右下悬浮）

- 黑色毛玻璃胶囊 `.capsule-pill`：播放图标 + 「Loina 电台」+ 正在播放状态；
- 外围 SVG 环绕进度条 `#cpRingRect`，随播放进度描边；
- 点击展开面板 `.capsule-panel`：歌单（5 首）与上一首 / 暂停 / 下一首控制；
- 胶囊下方独立小条 `#cpLrc`：显示当前歌词行，长句自动跑马灯；**面板内不显示歌词**；
- 胶囊歌单 5 首（归零者 / 星辰 / 星空物语 / 璃 / 飞蛾扑火），预览音由 Web Audio 现场合成 WAV blob。

### 7.8 底部 Dock

固定底部的毛玻璃应用栏 `#loinaDock`，三个入口：**首页 / 词典 / 播放器**，当前所在项高亮。

### 7.9 两个 iframe 子应用

| iframe | 子应用 | 职责 |
| --- | --- | --- |
| `#frame-dict` | MiNa 离线词典 | 3500+ 词库、本地 TTS、生词本，离线可用 |
| `#frame-player` | Mango 播放器 | 本地音频导入、LRC 歌词、ID3/FLAC 封面提取、播放控制 |

postMessage 协议：

| 方向 | 消息类型 |
| --- | --- |
| 主页 → 播放器 | `mango-play` / `mango-toggle` / `mango-shuffle` / `mango-prev` / `mango-next` |
| 播放器 → 主页 | `mango-lrc` / `mango-playlist` / `mango-time` / `mango-state` |

## 9. 红线（迭代时禁止改动）

以下模块为已调好的核心资产，任何改动需先单独确认：

1. 悬浮 AI 笑脸图标及其 CSS/JS；
2. 电台胶囊环绕进度条 `#cpRingRect` 及其进度刷新逻辑；
3. 封面提取 `tryId3` / `extractCover`（ID3v2 / FLAC 二进制解析）；
4. 胶囊下方歌词 `#cpLrc` 的现有形态（面板内两行歌词保持删除）。

## 10. 已知边界

- 留言板为**本机存储**：同设备同浏览器可见，换设备、清缓存即丢，别人打开链接看不到你的留言；真·多人共享需引入后端（如 Supabase），届时将是唯一离开纯单文件的改动；
- AI 概念工程 14 项与 MiNa AI 板块均为概念占位，无真实处理逻辑；
- 无账号体系，昵称为自由文本，「站长」标签仅存在于内置种子记录；
- 无单条留言删除、无分页、无敏感词过滤（本机场景无实际意义）。
