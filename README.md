# Loina｜梓墨的超级小站 ✨

> 一个移动端优先的前端小站，集合 **MiNa词典** + **Mango Player播放器**，带有灵动岛交互、极光动态背景、明暗双主题。
> 纯 HTML/CSS/JavaScript，无第三方框架依赖。

## 📝 项目介绍

这是我的个人数字自留地，三合一网页应用：

- 📖 **MiNa 词典**：哑光蓝白风格词典工具，支持 TTS 单词发音，本地词库
- 🎵 **Mango Player**：毛玻璃极光风格音乐播放器，带有黑胶动效
- 📱 **模拟手机端体验**：灵动岛交互、Dock 底部栏、动态极光背景、深色/浅色主题一键切换

站点优先适配手机端，也可在电脑浏览器打开预览。

## ✨ 功能特性

- ✅ 灵动岛动态交互，点击展开快捷面板
- ✅ 深色 / 浅色两套主题，设置自动本地存储
- ✅ 动态极光渐变模糊背景动画
- ✅ 首页快速查词，浏览器原生 TTS 单词朗读发音
- ✅ Dock 底部导航栏，快速切换首页 / 词典 / 播放器
- ✅ iframe 沙箱隔离子应用，页面转场加载动画
- ✅ 毛玻璃玻璃拟态 UI 风格，移动端优先适配
- ✅ 纯原生前端，无需后端，直接部署即可运行

## 🛠️ 本地运行

1. Clone 本仓库

```bash
git clone https://github.com/loina-1314/loina123.github.io.git
```

2. 直接打开主 html 文件，或者使用本地静态网页服务打开

> ⚠️ 直接本地双击打开部分浏览器会限制 iframe 功能，建议使用本地静态服务预览。

## 📦 部署方式（GitHub Pages）

1. 将全部代码 push 到你的 github 仓库
2. 仓库设置开启 GitHub Pages，选择 main 分支部署
3. 等待几分钟即可访问你的公开站点
